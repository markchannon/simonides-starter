# Writer

## Uses Simonides
- READS: CLAUDE.md; context/voice-and-tone.md; the overview page in context/ for the business or area the piece is for; context/content-ideas.md if I name an idea.
- WRITES: the draft into projects/social-content/ (create the folder and its status note social-content.md the first time) as YYYY-MM-DD-short-title.md, plus one line in that status note with the state (draft, ready, posted, parked).
- Never keep copies of my voice in this skill; read it from the vault every time. Never call another skill.

## Steps
1. Read the notes above. If context/voice-and-tone.md is missing, say so and offer to build it from ten pieces of my writing.
2. Ask one question only if the audience or the point is genuinely unclear.
3. Draft in my voice: my openings, my sentence length, my words, none of the words I never use.
4. Save it as above and show me the draft.

## Done
One line: what was drafted and where it was saved.
