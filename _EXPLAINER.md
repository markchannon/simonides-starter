# How my Simonides works

_Starter text from the Simonides starter kit. Claude rewrites it in recipe 5 and adds a line whenever something new is added._

**The idea.** One private folder of plain-text notes about me and my work. Claude reads it before it answers and writes to it when I say "remember this". I never organise anything; Claude does the filing, tagging and linking.

**The folders.** context is my world · people and organisations are who I know · projects are what I am doing · records are what happened · systems are how it runs · library is what I have read · daily is the diary.

**Remember this.** I say "remember this" and paste or talk. Claude checks whether it already has a note, plays it back if so, otherwise files a new one, links it, lists it in the index and logs it in today's diary.

**Safe and in sync.** The folder lives on GitHub as a private repository. My computer keeps its copy level every five minutes, and every version is kept.

**Code projects.** Websites, apps and tools I build in a coding tool live in their own GitHub repositories, listed in systems/code-projects.md. The daily tidy reads what changed in each one and shows it on my Daily page, with a question when it cannot see one.
