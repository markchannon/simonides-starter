# Skills registry

One row per skill: what it reads, what it writes, whether it is installed. The daily tidy adds a row for any installed skill missing here.

| Skill | Triggers | Reads | Writes | Installed |
|---|---|---|---|---|
| remember-this | "remember this", "save this", "note this", "what do I know about X", "use my brain" | CLAUDE.md, _CONVENTIONS.md, the notes it needs | the right note, CLAUDE.md, today's daily note, decisions-log | not yet (recipe 3) |
| writer | "write a post about X", "draft this in my voice" | context/voice-and-tone.md, the business overview page | projects/social-content/ | not yet (recipe 6) |

Source of each skill: skills/<name>/SKILL.md in this Simonides. To install one, say in a chat with your Simonides folder added: "Package ~/Simonides/skills/<name> as a skill I can install, and give me the exact clicks to add it." Then put the date in the Installed column.
